Hi — I'm Abdulrahman, a full stack web developer based in Egypt. I've spent the last few years building web applications where the backend actually holds up under real traffic and the frontend feels good to use.

My core is Django. I architect data models, write clean REST APIs with DRF, wire up authentication and permissions, background jobs with Celery, caching with Redis, and ship it all with Docker. On the front, I build the interface myself — no handing off half a product.

I care about the boring things that make software last: readable code, real tests, sensible migrations, and documentation the next developer won't curse me for. If you need someone who can own a product from the database schema to the last hover state — that's the job I like most.
